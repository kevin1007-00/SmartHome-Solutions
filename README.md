# SmartHome Solutions - Sitio Web de Domótica

## Descripción
Este proyecto consiste en el desarrollo de la primera versión estructural de un sitio web para una empresa de domótica llamada **SmartHome Solutions**. El objetivo es presentar información sobre servicios de automatización del hogar, permitiendo al usuario conocer la empresa y contactarse fácilmente.

## Estructura del Proyecto
El sitio web está compuesto por tres páginas principales:

- `index.html`  Página de inicio
- `nosotros.html` Información sobre la empresa
- `contacto.html` Formulario de contacto

Además, se incluye:
- Carpeta `css/` con estilos (`style.css`)
- Carpeta `img/` para recursos gráficos

## Características
- Navegación entre páginas mediante menú
- Uso de etiquetas semánticas de HTML5 (`header`, `nav`, `main`, `section`, `footer`)
- Inclusión de imágenes, listas y enlaces
- Formulario de contacto básico
- Diseño visual aplicado con CSS externo

## Tecnologías Utilizadas
- HTML5
- CSS3
- Editor: Visual Studio Code

## Diseño
Se implementó un diseño limpio y organizado, acorde a la temática tecnológica, utilizando colores sobrios y una estructura clara que mejora la experiencia del usuario.

## Ejecución
Para visualizar el proyecto:

1. Abrir la carpeta en Visual Studio Code
2. Ejecutar el archivo `index.html` con Live Server o en el navegador
